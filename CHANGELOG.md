# Изменения

## 1.2.1 — 22 октября 2026

- Группа «Избранное» теперь доступна и в основном списке серверов. Она
  использует те же отметки, что и окно выбора под кнопкой подключения;
  избранные серверы показываются вверху без дубликатов.
- Общий индикатор пинга непрерывно вращается до завершения или отмены проверки,
  сохраняя счётчик проверенных серверов для озвучивания.
- Разбор подписок и обработка больших GeoIP/GeoSite-файлов выполняются отдельно
  от интерфейса, чтобы индикаторы обновления не останавливались на обработке.
- Результаты пинга обновляют только нужные индикаторы и больше не сохраняют
  весь список серверов после каждого ответа.
- В Windows запуск и завершение процессов проверки задержки выполняются
  в рабочем потоке, освобождая поток окна для отрисовки и ввода.

## 1.2.0 — 15 октября 2026

- Личный build 2125: выбранный сервер отмечается подсветкой без галочки
  в основном списке и в общем окне выбора. Под названием сервера
  показываются транспорт и защита из его конфигурации. Ошибка обновления
  подписки отмечается красным треугольником рядом с названием и подсказкой.
  Экран импорта, результаты и QR обновлены в общем стиле приложения;
  добавлены очистка поля, Cmd/Ctrl+Enter и индикация сохранения.
  Отступы и флаги выровнены; после просмотра главным действием становится
  добавление серверов, повторная проверка остаётся доступной.
  Продолжение, добавление и повторная проверка представлены иконками
  с подсказками и областью нажатия 44 px.
- Личный проверочный build 2124: ядро Windows обновлено до
  1.14.1-extended-2.7.2 для совместимости с текущими VLESS REALITY-серверами.
  DNS-конфигурация и проверка VPN-службы переведены на новый формат ядра.
  Обработчик импорта Windows принимает адрес с одним `/` после `import`.
  WG/AWG с нестандартными reserved-байтами отклоняются с понятной ошибкой;
  сохранённые профили не изменяются. В окне выбора сервера оставлена подсветка,
  в основном списке сохранена галочка. Публичного обновления пока нет.
- Проверочный build 127: оставшаяся запись удаления старой 32-битной версии
  больше не мешает новой установке, если старой папки нет либо она пуста и
  проверки безопасности и завершения VPN пройдены. Содержимое старой папки и
  пользовательские профили не удаляются. В каталоге VPN-сервисов оставлен Honey.
- Проверочный build 126: исправлен запуск проверки каталога в установщике
  Windows. Ошибки прав каталога, завершения старого VPN и определения
  пользователя показывают разные диагностические коды. Установка сохраняет
  исходный профиль пользователя при повышении прав через отдельную учётную
  запись; права исходного процесса не изменяются. Раннее закрытие клиента
  локального канала больше не останавливает VPN-службу: приём повторяется с
  сохранением защищённого имени канала и корректной остановкой службы.
- Проверочный build 125: ссылки импорта из Telegram открывают экран импорта
  в Android, Windows и macOS. Windows принимает ссылку в уже открытом окне;
  повторный запуск не создаёт вторую VPN-сессию. Импорт требует явного
  подтверждения, некорректные ссылки отклоняются. Формат существующей кнопки
  HoneyVPN-бота сохраняется. iOS-приложение ещё не добавлено.
- Проверочный build 124: окно Windows открывается вертикальной панелью справа
  на всю рабочую высоту экрана с учётом DPI и панели задач. Строки настроек
  выровнены по центру, внизу добавлена фирменная подпись разработчика YuNiCode.
  IP/DNS-настройки Android применяются к разрешению доменных имён; Windows TUN
  охватывает IPv4 и IPv6. Порт 9090 зарезервирован, неподдерживаемый сохранённый
  DNS отклоняется без подмены; настройки без эффекта на платформе скрыты.
- Проверочный build 123: установщик Windows добавляет системную службу TUN.
  Права нужны при установке и обновлении; приложение запускается без UAC.
  Подключение использует встроенные правила маршрутизации и DoH по умолчанию;
  краткая недоступность контроллера не считается подтверждённым обрывом VPN.
- Вместо поиска серверов добавлена проверка задержки через профиль с прогрессом
  и остановкой. Hysteria2 проверяется своим протоколом; TCP-handshake больше
  не выдаётся за работоспособность VPN. Для WG/AWG измерение недоступно.
  Объёмные emoji-флаги встроены в приложение и одинаково выглядят на Windows
  и Android; буквенные префиксы страны скрываются только при отображении.
- Интерфейс в стиле Apple, светлая и тёмная темы, щит вместо сот, компактная
  боковая панель и мобильные вкладки с иконками. Большая самостоятельная
  кнопка сохраняет положение при смене состояния и прокрутке; сервер под ней
  открывает общий список всех подписок и ручных профилей. RU/EN, крупный текст,
  клавиатурные команды, озвучивание и контекстные действия сохранены.
- Начата macOS-основа: Runner, Apple datasource, NE-профиль и packet tunnel
  target с типизированным Libbox adapter, native counters и восстановлением
  точного session/profile ID. CI собирает закреплённый framework. Настоящий
  VPN требует подписи и испытаний; CoreReady остаётся false. iPhone следующим этапом.
- Бесплатная подписка содержит один стабильный сервер; повторный импорт
  и накопленные дубли исправляются, счётчик соответствует реальному списку.
- Обновление подписки сохраняет выбранность, избранность и ID; пустой ответ
  не удаляет рабочие профили. Параллельные обновления сохраняются последовательно.
- Импорт WG/AWG понимает комментарии, BOM и IPv6; неполная конфигурация больше
  не создаёт фиктивный сервер. Naive/TUIC корректно сохраняют URI credentials.
- Android VPN-служба использует выбранный SOCKS-порт и очищает дочерние
  процессы при ошибке. Конфигурации исключены из стандартного Android backup.
- Android выделяет конфигурацию и ресурсы каждой сессии отдельно; отменённый
  worker не публикует handles или поздние события. Readiness проверяет свой
  authenticated controller; TUN descriptor перед fork имеет собственный dup.
- Windows supervisor удерживает process handle, проверяет nonce и app parent
  identity, ждёт очистку перед остановкой и новым запуском. Старый или чужой
  порт 9090 не подтверждает новое подключение. Неизвестный journal блокирует
  запуск до проверки восстановления; детали и device QA — docs/PRIVATE_QA.md.
- Windows VLESS без TLS остаётся без TLS, TUN применяет пользовательские
  настройки DNS и маршрутизации. Остановка не сбрасывает чужой системный proxy
  и не убивает процессы других VPN-клиентов.
- Порты сохраняются атомарно; быстрые изменения настроек не теряют друг друга.
- Отмена подключения предотвращает поздний запуск VPN; события старой сессии
  не меняют состояние новой. Неиспользуемый плагин flutter_v2ray заменён
  собственной моделью статуса без дополнительного native VPN-ядра.
- WireGuard использует endpoint API ядра 1.13 на Android и Windows; TUIC
  реализован в Windows. Android ShadowTLS использует правильную цепочку
  Shadowsocks → ShadowTLS. NaiveProxy отмечен недоступным в текущем ядре.
- sing-box обновлён до совместимого 1.13.12-extended-2.1.2, tun2socks — до 2.7.0
  с Go 1.26.8 и 16 KB alignment. core-lock.json объединяет immutable revisions,
  SHA-256, ABI и build recipes; упаковка проверяет происхождение и версию.
- VLESS encryption/ALPN/insecure и точный path, Hysteria2 auth/port hopping
  сохраняются от импорта до подключения. Глобальный mux не отключает Vision.
  Известные неподдерживаемые AWG/VLESS/Hysteria поля больше не теряются молча;
  ошибка обновления подписки сохраняет старые серверы и показывается в интерфейсе.
- Обновление выбирает APK по ABI устройства. Версии prerelease сравниваются
  корректно; отсутствующий совместимый APK не заменяется случайной сборкой.
- CI проверяет код, тесты, версию и native ABI до сборки. Ручная проверочная
  сборка сохраняет артефакты, не меняя установщики сайта. Windows core закреплён
  по версии и SHA-256.

Проверки с реальным VPN на Android и Windows обязательны перед stable.
